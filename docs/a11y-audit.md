# Accessibility audit

Tested on the live site: https://lucky-umoka.github.io/student-finance-tracker/

- Lighthouse accessibility score (desktop): 100
- Lighthouse accessibility score (mobile): 100
- Keyboard-only pass: skip link, form errors, adds, edit, delete, settings, import and export all reachable with a visible focus ring
- Checked at 360px, 768px and 1024px; no sideways scolling of the page
- Console: no red errors during add, edit, delete, search, import and export
